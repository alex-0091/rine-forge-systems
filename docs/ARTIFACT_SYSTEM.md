# Workbench Artifact System & Deliverables (Phase AQ)

## 1. Overview
The **Workbench Artifact System** manages concrete, usable business deliverables generated by Rine Forge's specialized agents.

Instead of fleeting chat messages, each deliverable is stored as a versioned, inspectable, and editable `V5WorkbenchArtifact` entity.

---

## 2. Supported Deliverable Types

| Artifact Type | Generator Agent | Capabilities & Views |
|---|---|---|
| **`WEBSITE`** | `WebsiteBuilderAgent` | 7-page responsive structure (Home, Services, Pricing, About, Contact, FAQ, Booking), Tailwind CSS, desktop/tablet/mobile viewport switchers, live in-browser HTML code editor, standalone HTML download, one-click publish confirmation gate. |
| **`LOGO`** | `BrandGeneratorAgent` | Multi-concept parametric vector SVG marks, dark/light stage inspection, hex swatch copying with contrast ratios, typography pairings, aesthetic style transformations (`Minimal`, `Premium`, `Playful`, `Bold`), SVG download. |
| **`SPREADSHEET`** | `FinancialModelAgent` | 100% deterministic mathematical calculations, gross margins, fixed OPEX, net profit, break-even metrics, 12-month projections table, CSV spreadsheet export. |
| **`REPORT`** | `WebsiteAuditAgent` / `MarketResearchAgent` | 8-dimension conversion and technical scorecard, strict separation of verified facts from deductive recommendations, transparent disclosure of unmeasurable client-side metrics. |
| **`DOCUMENT`** | `BusinessPlanAgent` / `MarketingAgent` | Operational plans, customer acquisition strategies, content pillars, email sequences, and multi-channel campaign copy with explicit assumptions. |
| **`AI_AGENT`** | `WorkbenchExecutionService` | Blueprint specification for 24/7 AI employee deployments (voice, chat, WhatsApp) with tool bindings and operational schedules. |

---

## 3. Human Confirmation Gates (`requires_confirmation=True`)
To ensure enterprise safety and prevent unintended side effects:
- Any action with consequential real-world impact (e.g., publishing a website live to a public domain, connecting real Twilio phone numbers, triggering live CRM updates, broadcasting outbound outreach) requires explicit operator review and confirmation.
- Operators confirm actions via the `POST /api/v1/workbench/artifacts/{id}/confirm` endpoint, which transitions the artifact status to `PUBLISHED` and records an immutable audit log timestamp.
